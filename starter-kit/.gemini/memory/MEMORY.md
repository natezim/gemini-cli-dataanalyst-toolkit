# Project Memory

Project-private dynamic facts. Auto-appended by Gemini as it learns durable facts about this project. You can prune or edit at any time.

## How this file works

- **Gemini appends** durable project facts here as they come up — no permission needed.
- **You** prune, correct, or reorganize whenever you want.
- Format: `- [YYYY-MM-DD] <fact> — source: <session or file ref>`
- Loaded into every session as tier-3 memory (project-private).

What goes here:
- Project-specific quirks ("orders.created_at is UTC; reports use ET")
- Recurring preferences ("user wants p99 latency, not p95")
- Schema/system gotchas
- Decisions and why they were made

What does NOT go here:
- One-off session details
- Anything in `context/` already
- Cross-project preferences — those belong in `~/.gemini/GEMINI.md` via `/memory add` (you type it)
- Architectural conventions — those belong in `./GEMINI.md` or `./CONTEXT.md`
